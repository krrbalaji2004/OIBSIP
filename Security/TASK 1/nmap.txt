5. SECURITY ANALYSIS
-----------------------------------

Port 135:
MSRPC is used by Windows for communication between
network services and applications. Exposure can increase
the attack surface if the service is accessible from
untrusted networks.

Port 139:
NetBIOS Session Service supports older Windows network
communication and file/printer sharing. It should not
normally be exposed to untrusted external networks.

Port 445:
SMB is used for Windows file and printer sharing.
Improperly exposed or outdated SMB services can create
security risks. Access should be restricted to trusted
networks and systems should be kept updated.

Port 16992:
This port is associated with Intel Active Management
Technology (AMT) HTTP management. Management interfaces
should be protected and restricted to authorized users
and networks.
