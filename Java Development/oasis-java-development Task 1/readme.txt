# Number Guessing Game

## Objective

A Java-based number guessing game where the computer generates a random number between 1 and 100, and the user tries to guess it within a maximum of 7 attempts.

## Features

* Random number generation from 1 to 100
* User input using Scanner
* Too High and Too Low hints
* Correct answer notification
* Maximum 7 attempts
* Win/Loss result
* Play Again option
* Multiple round support
* Round summary
* Score tracking
* Input validation

## Technologies Used

* Java
* Scanner
* Random
* If-else statements
* While loop
* Do-while loop

## How to Run

Compile the program:

```bash
javac NumberGuessingGame.java
```

Run the program:

```bash
java NumberGuessingGame
```
