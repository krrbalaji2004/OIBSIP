## Oasis Infobyte Internship

**Track:** Web Development and Design

## Project Description

This is a personal portfolio website created using HTML, CSS, and JavaScript.

The website showcases my profile, skills, education, projects, certificates, resume, and contact details.

## Features

* Home section
* About Me section
* Skills section
* Education section
* Projects section
* Certificates section
* Contact form
* Resume download
* GitHub and LinkedIn links
* Responsive design
* Mobile navigation
* Back to top button
* Form validation

## Technologies Used

* HTML5
* CSS3
* JavaScript
