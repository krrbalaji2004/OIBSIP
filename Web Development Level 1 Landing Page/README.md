# TechNova - Landing Page

## Oasis Infobyte Internship

**Track:** Web Development and Design  
**Level:** Level 1  
**Project:** Landing Page

## Project Description

TechNova is a responsive technology learning landing page designed using HTML and CSS.

The website provides information about technology courses and encourages users to start their learning journey.

## Features

- Responsive landing page
- Navigation bar
- Hero section
- Course section
- Why Choose TechNova section
- Call-to-action section
- Footer
- Mobile responsive design

## Technologies Used

- HTML5
- CSS3
